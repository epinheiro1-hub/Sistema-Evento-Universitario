# Sistema de Eventos Universitários

Projeto desenvolvido como atividade acadêmica do curso de Engenharia de Software.

O objetivo do projeto é criar uma página web para divulgação e visualização de eventos acadêmicos de uma universidade, como palestras, minicursos, workshops e oficinas.

## Sobre o projeto

O sistema apresenta uma página com informações sobre eventos universitários, permitindo visualizar detalhes como:

- Nome do evento
- Data
- Horário
- Local
- Descrição
- Tipo de evento

O projeto foi desenvolvido utilizando apenas HTML e CSS, conforme os requisitos da atividade.

## Tecnologias utilizadas

- HTML
- CSS
